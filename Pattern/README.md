# C++ Pattern Practice

I wrote these 14 pattern printing programs to get comfortable with nested loops and `if-else` conditions in C++. Doing these really helped clear my logic before moving on to Arrays and Data Structures.

## Patterns Coded
* `binary_triangle.cpp` (0-1 alternating triangle)
* `butterflypattern.cpp`
* `column_number_square.cpp`
* `continuous_number_square.cpp`
* `Floyd's_Triangle.cpp`
* `Full_Symmetrical_Pyramid.cpp`
* `half_pyramid_numbers.cpp`
* `half_pyramid_stars.cpp`
* `hollow_square.cpp` (Square with only borders)
* `increasing_number_triangle.cpp`
* `inverted_right_half_pyramid.cpp`
* `palindromic.cpp`
* `reverse_number_triangle.cpp`
* `zigzag_stars_pattern.cpp`
